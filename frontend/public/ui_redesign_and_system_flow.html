Version: 2.4 Production • Frontend: Vanilla JS / Bootstrap 5.3 / SCSS • Backend: Express 5 / Socket.IO • Database: PostgreSQL 18 (Prisma ORM)
1. Executive Summary & Full-Stack Architecture

This enterprise web application provides a unified, cross-company identity and workforce attendance ecosystem. It links an employee's verified career history, past salaries, credentials, and real-time attendance punches using universal 1D Code 128 barcodes and 2D QR codes.

Client Presentation (SPA)

Single Page Application driven by HTML5 History API & hash routing in EmployeeApp. Interactive scanner via Html5Qrcode, dynamic barcodes via JsBarcode and qrcode.

Gateway & WebSockets

Node.js Express 5 server running on port 5000 with /api/v1/ REST endpoints, JWT authentication, and bidirectional Socket.IO WebSocket stream for live attendance punches.

Persistence Tier

PostgreSQL 18 database managed with Prisma ORM client. ACID-compliant tables for identity, dynamic employment history, punches, company shift policies, and admin accounts.

2. Core User Personas & Workflows
1 Persona 1: Company / HR Administrator Flow
Admin Journey

Manages workforce onboarding, credential generation, shift policies, and offboarding.

  1. Authentication: Visits #auth, signs in with username/email or uses 1-Click Demo buttons (NexGen Cloud Systems, TCS, Infosys). Receives JWT admin token.
  2. New Employee Onboarding: Accesses #verification, fills employee demographics, adds previous company cards (with auto-calculated tenure), and uploads passport photo & salary slips.
  3. Universal Barcode Issuance: System submits to /api/v1/persons and generates a dynamic Code 128 barcode and QR Code ID pass ready for printing or SVG/PNG download.
  4. Shift & Grace Period Management: Configures shift start time (e.g. 09:00:00) and grace period (e.g. 30 min) in the settings modal.
  5. Offboarding & Lock: Enters employee final working date via "Enter Last Date". The record is permanently locked (is_active = false), revoking attendance scanner credentials with 403 Forbidden.
2 Persona 2: Front Desk Optical Scanner Flow
Physical / Device Terminal

Unattended front-desk station running on a tablet, PC, or optical scanner terminal.

  1. Webcam Activation: Scanner opens #attendance, activating the webcam feed with animated laser scanning overlay.
  2. Badge Presentation: Employee holds digital badge or printed card in front of camera.
  3. Smart Toggle & Verification: Evaluates today's records: if first punch → Check-In; if second punch → Check-Out. Computes shift duration.
  4. Debounce & Audio Feedback: Plays audio chime and triggers 3-second cooldown to avoid duplicate scans.
  5. Real-time Broadcast: Emits WebSocket event attendance:punch, updating the HR manager's live activity stream instantly.
3 Persona 3: Employee Self-Service Flow
Employee Self-Service

Telecommuting and on-site staff managing daily shifts and attendance records.

  1. Sign In: Logs in with Employee Code (EMP-001) and PIN (1234) at #auth.
  2. Remote WFH Check-In / Out: Clicks one-touch daily punch with live shift duration timer and cutoff window status.
  3. Annual Summary: Views annual metric cards: Total Working Days, Present Days, Absent Days, Paid Leave Quota (24 days), Leaves Taken, Leaves Remaining.
  4. Historical Records: Browses personal chronological punch history and work mode tags (Remote vs Office).

5. Complete Backend API & Real-Time WebSockets

Base URL: http://localhost:5000/api/v1

Method Endpoint Payload / Parameters Description & Response
POST /auth/admin-login identifier, password Authenticates company admin, returns JWT token and company payload.
POST /auth/admin-register company_name, username, email, password, state Registers new company account and default shift configuration.
POST /auth/employee-login employee_code, pin Authenticates employee for self-service portal.
GET /persons Query: company_name, status Retrieves employee directory with employment details.
POST /persons name, email, mobile, company_name, monthly_salary, experience Creates person, details, departments, and generates unique barcode hash.
POST /employees/:id/deactivate end_date, remarks Offboards employee, permanently locks record, sets is_active = false.
POST /attendance/barcode-punch barcode_data, terminal_sn, location Validates barcode status, toggles Check-In/Out, broadcasts via WebSocket.
POST /attendance/wfh-check-in employee_code, notes, work_mode Remote employee self-service check-in/out.
GET /attendance/my-annual-summary Query: year (e.g. 2026) Returns annual totals (Present, Absent, Leave quota, Leaves remaining).
GET /attendance/settings Query: company_name Returns shift start time and grace period minutes.
WS ws://localhost:5000 Event: attendance:punch Real-time broadcast dispatched to Scanner activity stream on every punch.
6. UI Redesign Guidelines & Modernization Strategy
Critical Rule: Preserve Element IDs

All frontend event listeners and DOM manipulation in src/assets/js/employee-system.js attach directly to HTML element IDs. When modifying or replacing HTML tags, classes, or templates, keep all existing id attributes intact to guarantee that all buttons, forms, webcam scanners, and modals continue to function seamlessly.

Layout Modernization
  • Sidebar App Shell: Transition from vertical scroll sections into a modern collapsible sidebar (Gateway, Directory, Onboarding, Attendance, Analytics) with a fixed utility topbar.
  • Card Elevation & Glassmorphism: Adopt 1px solid rgba(226,232,240,0.8) borders, soft shadows (shadow-sm, shadow-md), and 16px corner radius.
Visual Polish & Typography
  • Typography: Use Plus Jakarta Sans for headings, Inter for clean data tables, and JetBrains Mono for barcode strings and codes.
  • Scanner Dark Mode: Implement a high-contrast dark terminal mode for the camera scanner with glowing cyan scanlines and punch confirmations.
